# Repository destination

- The canonical repository for future updates is the private repository
  `https://github.com/udg-lai/LPR-GNN`.
- When publishing authorized changes, use `origin` (`udg-lai/LPR-GNN`).
- The original `josepsuy/LPR-GNN` repository is preserved unchanged. Do not push
  changes to it unless the user explicitly requests that destination.
- Keep these repository destinations distinct from the sources of benchmark
  instances and third-party software.
